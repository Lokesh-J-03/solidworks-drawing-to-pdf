# SolidWorks Drawing to PDF Converter

A Windows desktop application for batch converting SolidWorks `.SLDDRW` drawing files into PDF files using the SolidWorks 2026 API.

## Features

- Batch convert multiple SolidWorks drawings
- One PDF generated per drawing
- Supports multi-sheet drawings
- Input folder selection
- Output folder selection
- Progress bar
- Conversion log
- SolidWorks 2026 automation

## Requirements

- Windows
- SolidWorks 2026
- Python 3.14+ (when running from source)
- pywin32

## Usage

1. Select the folder containing `.SLDDRW` files.
2. Select the output folder.
3. Click **CONVERT TO PDF**.
4. The application creates one PDF for each drawing.
